# Jatin Mourya — React Portfolio

A responsive dark portfolio built with React + Vite, with neon blue/purple accents.

## Run it on Windows

1. Install Node.js if you have not already.
2. Extract this ZIP.
3. Open the extracted `jatin-react-portfolio` folder in VS Code.
4. Open **Terminal → New Terminal**.
5. Run these commands one by one:

```powershell
npm install
npm run dev
```

6. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Personal photo

The photo is already included as `public/jatin-photo.jpg`. To change it later, replace that file with another image and keep the same filename.

## Edit your portfolio

- Main page and text: `src/App.jsx`
- Styling: `src/styles.css`
- Browser tab title: `index.html`
- Resume: add your PDF to `public/resume.pdf` and add a Resume link/button when your resume is ready.

## Before publishing

- Check that every project description and link matches your actual work.
- Add a real email address you want to show publicly.
- Add a resume PDF when it is ready.
- Deploy with Vercel, Netlify, or another static hosting service.
